# Static sites: automated checks before each push
Set these up once as npm scripts and run them in CI:
- HTML validation (`html-validate`);
- link checking (`linkinator`), skipping only the specific hosts that block bots;
- accessibility (axe) on every page;
- contrast of interactive states (hover and focus), not just the default state;
- no horizontal overflow at 320px;
- canonical URLs pointing at the real domain;
- an Open Graph image generated by a script from an HTML template (never hand-edited) and checked against the page;
- no untracked files the site depends on.

Also:
- `sitemap.xml`, `robots.txt` and a root `favicon.ico`.
- A `.gitattributes` that fixes line endings.
- Self-hosted fonts, so the privacy policy can honestly say no third-party requests.
- A contact form that goes through a form service or your own worker, with a clear "Message sent" state and a short privacy note.
