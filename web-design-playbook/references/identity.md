# Set the identity first
- Put every colour, font and radius in tokens on `:root`, with a dark-mode set. Components only use tokens.
- Pick a deliberate pairing, for example:
  - a serif for headlines with a sans for text and a mono for data labels (an editorial or consultancy feel);
  - one geometric sans throughout (a friendly app feel).
- Self-host fonts.
- Neutrals carry a slight hue from the accent. One accent colour for actions, used sparingly.
- Write a short DESIGN.md per product (tokens, components, tone) so future changes stay consistent. Studying other products' DESIGN.md files (fintech and health apps are good references) helps when choosing a direction.
