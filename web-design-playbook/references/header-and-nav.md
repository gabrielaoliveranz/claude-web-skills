# Header and navigation
- A sticky pill header with a frosted background, offset by the safe-area inset.
- Optional: the header takes the colour of the full-width section underneath. Sample only full-width sections, not cards.
- Language picker with flags. On phones the menu spans the bar's width, and the header never wraps to a second line in any language.
- A footer with a back-to-top button. Pages opened from the footer start at the top.
